The SuDu AI logo. `Logo` is the full lockup and the default choice; `LogoIcon` is the alien head alone for square or space-constrained contexts.

```jsx
<Logo height={24} />
<Logo height={24} color="var(--primary-container)" />
<LogoIcon height={32} color="var(--brand-obsidian)" />
```

Both are single-color and inherit through `color`. Never recolor outside the brand palette, never outline, never rotate, never add effects, never rebuild the lockup by pairing `LogoIcon` with live type — the supplied wordmark lettering is artwork, not Figtree.
