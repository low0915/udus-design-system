Signals live system state — agent mode, engine health, anomaly alerts.

```jsx
<StatusPill status="ok">Agent Idle</StatusPill>
<StatusPill status="ok" pulse>Autonomous Mode: Active</StatusPill>
<StatusPill status="error" pulse>Anomaly Index: 98.4%</StatusPill>
```

One per region; the glowing dot is the brand's liveness signal and loses meaning if repeated.
