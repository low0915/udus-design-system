# Charts

Use [the approved slide guide](../../references/slides/approved-style.md) and [editable chart recipes](preview.html). Approved visual examples: [stock-status bars](../../assets/slide-references/approved-slide-06.png), [received/fulfilled trend](../../assets/slide-references/approved-slide-07.png).

Prefer native editable charts in presentation tools. Use Figtree for axes, legends and value labels, ivory backgrounds, obsidian ink, deep-teal primary data and muted-green comparisons. Keep scales, units, labels and legends clear; label demo data. Read [slide data rules](../../references/slides/data-and-claims.md). Existing CSS/HTML recipes remain construction examples rather than production claims.
