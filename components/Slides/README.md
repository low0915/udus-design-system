# Slides

Current source style: approved plugin v0.3.0. Read [the approved guide](../../references/slides/approved-style.md), open [the visual gallery](preview.html), and use [the older editable recipes](recipes.html) as construction examples. The approved guide takes precedence for slide typography, spacing and logos. The gallery is a reference, not an editable deck or live-data report.

Use Figtree, bold headings, consistent title-to-subtitle-to-content gaps and meaningful grouping. Use [the explicit logo colorways](../../assets/Logos/README.md). Layout examples adapt to the message; do not force every deck into the same eight-slide sequence.
